# VanaBROWSer

A desktop browser prototype built with Electron and Chromium.

## Features

- Dark VanaBROWSer start page
- Search the web with Google using any text
- Open websites by entering a domain or URL
- Embedded Chromium page view
- Back, forward, reload, and home controls
- Quick links to Google, YouTube, GitHub, and Wikipedia

## Run on Windows

1. Install [Node.js LTS](https://nodejs.org/).
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   npm install
   npm start
   ```

Electron bundles Chromium, so the browser page runs inside the desktop app. This is an early prototype, not yet a production-ready browser.
